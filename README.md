# 🌲 Forest Fire Prediction System

An AI-powered Forest Fire Prediction web application that analyzes environmental and weather-related parameters to predict the probability of forest fires using Machine Learning.

🔗 [https://forest-fire-predict--am2802555.replit.app/](https://forest-fire-predict--am2802555.replit.app/)

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Uttakarshin/Forest-Fire-prediction.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd Forest-Fire-prediction
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run Application

```bash
python app.py
```
